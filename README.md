# ตรวจสลากกาชาด ศรีสะเกษ 2570 (Next.js)

หน้าประชาชน `/` ตรวจเลขสลาก 5 หลัก + ดูผลทุกรางวัล (อัปเดตอัตโนมัติทุก 15 วิ)
หน้าเจ้าหน้าที่ `/admin` กรอกผลระหว่างออกรางวัล (ใช้รหัสผ่าน)

## Deploy บน Vercel
1. อัปโหลดโฟลเดอร์ขึ้น GitHub แล้ว Import ที่ vercel.com/new
2. แท็บ Storage → เพิ่ม **Neon Postgres** (Marketplace) → เชื่อมกับโปรเจกต์ (ตัวแปร `DATABASE_URL` ถูกเพิ่มให้เอง ตารางสร้างอัตโนมัติ)
3. Settings → Environment Variables → เพิ่ม `ADMIN_PASSWORD`
4. Redeploy

## รันในเครื่อง
npm install && cp .env.example .env.local && npm run dev
(ใส่ `DATABASE_URL` ของ Neon ใน .env.local)

## ปรับรางวัล
แก้ `lib/prizes.js`

## ฐานข้อมูล (Postgres)
- `customers` ชื่อ/เบอร์/ที่อยู่/หมายเหตุ · `tickets` เลขสลาก 5 หลัก (1 เลข = 1 ลูกค้า) + สถานะรับรางวัล · `kv` ผลรางวัล
- หน้าเจ้าหน้าที่: `/admin/customers` ลงทะเบียน/ค้นหาลูกค้า (กรอกเลขเป็นช่วงได้ เช่น 00010-00020), `/admin/winners` ดูผู้ถูกรางวัลและบันทึกการรับรางวัล
- PDPA: เก็บเท่าที่จำเป็น ไม่เก็บเลขบัตรประชาชน, ข้อมูลลูกค้าไม่แสดงบนหน้าประชาชน, ใช้รหัสผ่านที่เดายาก
